# SECURITY

## Reporting

Reports go through the repository only: Security tab, then Report a vulnerability. No other channel exists.

## What counts

A vulnerability is a defect in AEDIS instruments (linters, compilers, verifiers, drift scanners) that makes them accept invalid state or reject valid state.

## Handling

Reports are reviewed; confirmed vulnerabilities are fixed in the corpus. No response commitments, no timelines, no support for third-party use. Questions about running AEDIS are not security reports.
